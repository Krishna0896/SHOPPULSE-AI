🚀 Excited to share my latest portfolio project — **SHOPPULSE AI: AI-Powered Sales Analytics & Business Intelligence Platform!**

I built this project to bring together traditional business intelligence, machine learning, time-series forecasting and Agentic AI into one integrated solution.

**🔍 What does SHOPPULSE AI do?**

📊 **Business Intelligence with Power BI**
- Interactive sales and profitability dashboards
- DAX measures and business performance analysis
- Historical sales trends and category-level insights

🐍 **Python Analytics & Machine Learning**
- Data preparation and business analysis using Pandas
- Transaction-level sales prediction using Linear Regression
- 12-month category-level sales forecasting using Holt-Winters Exponential Smoothing
- Model evaluation using MAE, RMSE and R²

🤖 **Agentic AI Integration using MCP**
- Connected Claude Desktop with a custom Python MCP server
- Integrated Microsoft's Power BI Modeling MCP
- Enabled Claude to retrieve Python analytics and query the Power BI semantic model
- Built tools for sales forecasting, forecast validation, business analysis and recommendations

**🛠️ Technology Stack**

Python | Pandas | NumPy | Scikit-learn | Statsmodels | Power BI | DAX | Claude Desktop | Model Context Protocol (MCP)

**💡 My biggest takeaway**

The most interesting part was connecting Claude with both Python analytics and Power BI through MCP, allowing it to retrieve actual business data and assist with analytical questions using natural language.

This project helped me explore how traditional BI and predictive analytics can evolve into AI-assisted business intelligence.
